# GMM₂阶段汇报图表说明

## 推荐放入汇报正文的5张主图

1. `figure01_scene_coverage`：左图说明200个设计场景在基准速度和普通/激烈类别上的覆盖，右图说明实际组合加速度P95并不等同于设计标签。160个激烈设计场景中134个实际P95≥0.60；40个普通设计场景中也有6个达到该阈值，因此后续结果同时按设计类别和实际强度报告。0.60和0.80仅为实际强度参考线。
2. `figure02_overall_test_effect`：使用40个test场景等权RMSE。History将下一步vy/r RMSE由F1的0.18222/0.02204降到0.00334/0.00346，并在Current基础上进一步降低25.0%/9.4%。上排保留完整量程，下排从零开始放大Current与History，避免截断坐标轴夸大差别。
3. `figure03_per_scene_test_effect`：横轴是固定场景编号，不是时间。每个场景均保留F1、Current和History，显示总体收益不是只来自一条漂亮轨迹；普通设计场景的r误差相对更难稳定获益。浅绿色背景仅标识普通设计类别。
4. `figure04_representative_state_and_error_overview`：前三行是按类别中位表现选择的普通弯、高速换向和制动入弯，第四行是已记录的局部退化窗口。状态图显示Current/History多数时刻更贴近Chrono，误差图则保留History在退化窗口中过量修正的事实。所有曲线对齐到相同目标时刻`t+0.05 s`。
5. `figure05_history_benefit_distribution`：vy上History相对Current改善32个场景、退化8个；r上改善20个、退化20个，说明历史收益并不普遍一致。上排给出百分比，下排给出绝对RMSE差，避免Current误差很小时出现小分母夸张。

## 附图

每个代表场景另有一张状态图`figure04a_*`和一张误差图`figure04b_*`，适合答疑时放大。`validation_capacity_selection.png`和三个标签回代图可作为方法验证附图。

## 统一限制

所有时间曲线都是连续时刻上的逐拍一步预测，目标对齐到`t+0.05 s`，不是自主多步预测。GMM₂尚未接入闭环；曲线中的残差或误差波动不能解释为GMM₂造成了车辆振荡。图表没有删除失败、局部退化或低收益样例，代表场景选择不参与模型训练或配置选择。
