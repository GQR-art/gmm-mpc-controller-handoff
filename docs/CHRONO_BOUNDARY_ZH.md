# Chrono复现边界

本次验收覆盖四个模型的离线推理、短历史构造和原F₁修正QP参考重放，不运行新的Chrono场景。F₁参考重放使用真实train样例的状态、U₀、曲率、速度预瞄，仅验证控制器计算，不冒充完整车辆闭环。

已提供200场景生成代码及其静态Python依赖快照、车辆JSON、转角标定和地形配置。完整原始日志未随包提供。

外部运行依赖为原项目使用的Chrono构建及车辆数据，代码保留的配置入口包括CHRONO_MPC_CHRONO_RELEASE_DIR和CHRONO_MPC_CHRONO_DATA_DIR。需要GolfLike3D_v1车辆配置、相关GolfLike轮胎JSON及Chrono自带Sedan动力总成等资产。本轮不打包整套外部Chrono安装，也没有验证新机器上的Chrono运行。

src中的历史实验入口仍可能使用历史日志、Stanford原始会话和D盘路径。它们为研究源代码快照，不是可直接运行的跨机器仿真发行版。新控制器开发可参考它们，纯模型开发无需安装Chrono。

当前基础控制器为FoundationBridge；控制周期0.05 s、物理步长0.002 s、20步预测。纵向PI默认kp=0.25、ki=0.08、积分限幅5、死区0.05，实际采集器按此初始化。四轮制动监督器和执行器映射以随包源代码为准。下一阶段如需要跨机器完整闭环运行，应另行完成Chrono环境部署和小场景复现，不能将本次推理验收当作该项已通过。
