# 冻结 F₁ 的实际请求序列离线回放

## 结论

在不修改 `FoundationBridge`、GMM₁、控制器或原始200场景日志的前提下，离线回放已完成。200个场景均有合格起点，共22183个；按原划分为 train=13296、validation=4381、test=4506。重叠窗口始终保留 `scenario_id/overlap_group`，不能按独立场景计数或拆分。

三个train先导样例为普通弯 `F1C200_N2_005`、40 m/s高速换向 `F1C200_A2_029`、40 m/s制动入弯 `F1C200_A4_019`。它们按合格时间序列的中点确定，不按误差结果筛选。首步与已有一步残差最大绝对差为 3.580e-16，容差1e-10，结果：通过。通过后才生成批量多步数据。

全批次共生成443660个“起点×预测节点”记录。全批次首步最大绝对差为7.174e-14，仍低于1e-10。结构复核确认443660个键全部唯一，所核对的残差与速度差字段没有非有限值，逐场景分时域统计恰为200×20=4000行。

## 固定的 F₁ 回放语义

在线基础模型保持原式：`F₁(U₁)=F₀(U₁)+Cₖ(U₀)`。GMM₁在起点只查询一次，日志中保存的 `Cₖ(U₀)` 在20个节点冻结；本回放直接读取该修正，不重新查询、不缩放、不递归注入。

离线回放为 `F₁,replay = F₀(U_exec_request)+Cₖ(U₀)`。`U_exec_request` 是闭环在未来各控制周期实际发出的**请求路轮转角**，不是转向机构测得的实际转角。原F₁接口本来接收请求转角，因此没有把实际转角替换进模型。测量转角单独保存用于解释执行器响应。

未来请求只用于离线构建回顾标签，不是在线可用特征。参考曲率、速度预瞄和GMM₁修正均冻结为起点日志中的值。Chrono纵向仍由PI和四轮制动监督器真实演化，而回放使用起点冻结的速度预瞄；因此结果命名为“实际横向请求序列回顾残差”，不能称严格同完整输入的纯动力学残差。数据中保存了 `actual_vx-preview_speed` 供分解这一影响。

## 三类误差与时间对齐

- 跟踪误差：Chrono相对运行时参考投影的 `ey/epsi`，每个正式控制点保存一次。
- 一步预测残差：起点后0.05 s的Chrono状态减上述F₁回放；`epsi`做角度环绕，`r`按普通角速度差，不做wrap。
- 多步预测残差：同一起点后0.05–1.00 s、共20节点的Chrono状态减F₁回放。位置和航向真值统一投影到起点保存的各节点参考坐标。

每个起点要求连续0.20 s物理历史（101个0.002 s记录）、完整1.00 s正式区间（501个0.002 s记录）、20个保存预测节点及20个后续闭环请求。无法使用的控制点及互斥原因见 `unavailable_start_reasons.csv`。

## 输出

- `eligible_starts.csv`：合格起点、设计类别、实际强度、历史/未来边界和场景分组。
- `tracking_error_control_cycles.csv.gz`：跟踪误差。
- `one_step_actual_request_residual.csv.gz`：一步残差及全部组成量。
- `multistep_actual_request_replay.csv.gz`：多步残差、原F₁、回放F₀、冻结C、回放F₁、Chrono真值、请求/实际转角及纵向差异。
- `per_scene_horizon_statistics.csv`：逐场景、逐时域RMSE/MAE和速度预瞄差异。
- `aggregate_horizon_statistics_by_split.csv`：按原划分汇总的分时域结果。
- `pilot_error_summary.csv`：三个先导样例的四状态误差摘要。
- `validation_status.json`：行数、唯一键、非有限值和首步一致性复核。
- `pilot_*`与`plots/`：三个先导起点的0.20 s历史、输入和四状态代表曲线。

本轮没有训练GMM₂，也没有研究其闭环接入。
